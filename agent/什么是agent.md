## 什么是agent

### 前言

我们一直都在聊 agent 。那么 agent 到底是什么。已经 agent 的是如何工作的呢？

### agent 

Agent（智能体）是一个能够**感知环境、做出决策、并执行行动**以达成目标的程序。
有推理、规划和记忆能力，并且具有一定的自主性，能够自主学习、适应和做出决定。   

一句话总结就是：AI agent 是一个软件实体，可以感知环境，采取行动并从经验中学习。我们可以将 AI agent 视为一个能够根据人类设定的方向，自主执行任务的数字助手或机器人。   

AI agent 的几个主要功能：  

1、推理：这个核心认知过程，需要使用逻辑和可用信息得出结论，进行推断已经解决问题，具有强大推理能力的AI智能体，可以分析数据，识别模式，并根据信息和上下文做出明智的决定；

2、行动: 根据决策，计划或者外部输入采取行动或执行任务的能力对于 AI 智能体和外部环境进行交互和实现目标很重要。其中包括 AI 自身的物理动作，或发送消息、更新数据或触发其他流程等数字操作；  

3、观察：通过感知或者感应手机有关的环境的情况；这会涉及到多钟感知形式，例如计算机视觉、自然语言处理或传感器数据分析等；
