## 什么是agent

### 前言

我们一直都在聊 agent 。那么 agent 到底是什么。已经 agent 的是如何工作的呢？

### agent 

Agent（智能体）是一个能够**感知环境、做出决策、并执行行动**以达成目标的程序。
有推理、规划和记忆能力，并且具有一定的自主性，能够自主学习、适应和做出决定。   

一句话总结就是：AI agent 是一个软件实体，可以感知环境，采取行动并从经验中学习。我们可以将 AI agent 视为一个能够根据人类设定的方向，自主执行任务的数字助手或机器人。
